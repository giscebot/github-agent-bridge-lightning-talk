# GitHub Agent Bridge — lightning talk

Una presentació curta en Slidev sobre com `github-agent-bridge` converteix
esdeveniments de GitHub en feina durable i governada per a agents OpenClaw.

## Executar

```bash
pnpm install
pnpm dev
```

## Validar i exportar

```bash
pnpm build
pnpm export
```

El deck està pensat per a **6–7 minuts**. Les notes del ponent són dins de
`slides.md`. Les captures provenen del repositori oficial del producte i
mostren dades operatives de demostració; no contenen secrets.
